
FINAL PERMISSION MODEL
Main Committee:
- View all 18 Pradeshikams
- Add/delete members
- Select any Pradeshikam when adding a member
- Add payments
- Edit submitted payments
- Delete submitted payments
- View payment history
- View full Activity History

Pradeshikam:
- View only its own Pradeshikam
- Add/delete members in its own Pradeshikam
- Add payments
- Cannot edit submitted payments
- Cannot delete submitted payments
- View own payment history
- Cannot view Activity History

Audit:
- Member add/delete actions are recorded.
- Main Committee payment edits/deletions are recorded.
- Deleted payment records remain represented in audit history.
- Multiple receipts belong to one member.
